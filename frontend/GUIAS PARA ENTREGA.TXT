## 🔧 PASOS DE INSTALACIÓN

### PASO 1: Preparar el Backend

**1.1 - Habilitar CORS en el backend**

Abre `backend/src/app.js` y añade DESPUÉS de las importaciones:

```javascript
import cors from 'cors';
```

Y DESPUÉS de `const app = express();` añade:

```javascript
// Habilitar CORS
app.use(cors());
```

**1.2 - Instalar CORS en el backend:**

```bash
cd backend
npm install cors
```

### PASO 2: Crear estructura del Frontend

```bash
# Crear carpeta frontend
mkdir frontend
cd frontend
```

### PASO 3: Copiar todos los archivos que te envié

Copia TODOS los archivos de la carpeta `frontend-react` que te envié a tu carpeta `frontend/`

Estructura debe quedar:
- ✅ `package.json`
- ✅ `vite.config.js`
- ✅ `index.html`
- ✅ `src/` (con todos los archivos dentro)

### PASO 4: Instalar dependencias del Frontend

```bash
cd frontend
npm install
```

Esto instalará:
- React
- React Router DOM
- Axios
- Vite

### PASO 5: Iniciar ambos servidores

**Terminal 1 - Backend:**
```bash
cd backend
npm start
```
Debe estar corriendo en `http://localhost:8080`

**Terminal 2 - Frontend:**
```bash
cd frontend
npm run dev
```
Debe estar corriendo en `http://localhost:5173`

## 📝 PRUEBAS

### 1. Agregar productos desde el backend

Usa Postman o la vista `/realtimeproducts` para agregar productos:

```bash

  "title": "Laptop Gaming",
  "description": "Laptop de alto rendimiento",
  "code": "LAP001",
  "price": 1500,
  "stock": 10,
  "category": "Electrónica"
}
```

### 2. Probar el frontend

1. **Ver productos:** `http://localhost:5173/`
2. **Filtrar por categoría:** Usa los dropdowns
3. **Cambiar orden:** Precio menor a mayor / mayor a menor
4. **Ver detalle:** Click en "Ver Detalles"
5. **Agregar al carrito:** Click en "Agregar"
6. **Ver carrito:** Click en "🛒 Carrito" en el header
7. **Modificar cantidad:** Usa los botones +/-
8. **Eliminar producto:** Click en "Eliminar"
9. **Vaciar carrito:** Click en "Vaciar Carrito"

## 🐛 TROUBLESHOOTING

### Error: "Network Error"
- ✅ Verifica que el backend esté corriendo en puerto 8080
- ✅ Verifica que CORS esté habilitado
- ✅ Revisa la consola del navegador (F12)

### Error: "Cannot find module"
```bash
cd frontend
npm install
```

### Los productos no aparecen
- ✅ Verifica que hay productos en MongoDB
- ✅ Abre `http://localhost:8080/api/products` y verifica que devuelva datos

### El proxy no funciona
- ✅ Verifica `vite.config.js`
- ✅ Reinicia el servidor de Vite
